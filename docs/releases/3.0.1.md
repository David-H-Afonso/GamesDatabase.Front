# Games Database Web 3.0.1

## English

- Restore the Cover-to-Hero display fallback throughout Covers, shelves, details
  and other shared artwork surfaces. A real Cover remains the first choice.
- Missing/blank or failed Cover images try Hero once. If both are unavailable,
  the normal placeholder remains; identical URLs are not retried in a loop.
- This is presentation only: no stored image URLs, migrations or API changes.
  Hero/Logo and editor/metadata image previews retain their exact-source behavior.
- Compatible with API 3.0.0. This hotfix does not include subsequent local
  duration-autofill or Focus-isolation work.

## Español

- Recupera el respaldo de Hero cuando falta Cover en Covers, estanterías, fichas
  y demás superficies que comparten imágenes. La Cover real sigue teniendo prioridad.
- Si Cover está vacía o falla, se prueba Hero una vez. Si fallan ambas, se muestra
  el estado sin imagen; no se repite indefinidamente una URL idéntica.
- Solo presentación: sin cambiar URL guardadas, migraciones ni API. Hero/Logo y
  las previews del editor/autorrellenado conservan su fuente exacta.
- Compatible con API 3.0.0. No incluye las mejoras locales posteriores de
  duraciones automáticas ni aislamiento de Focus.
