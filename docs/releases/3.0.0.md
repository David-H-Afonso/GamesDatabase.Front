# Games Database Web 3.0.0

## English

### Your collection, from first use to the next game

- Configurable Home, Library, Focus, Playlists, manual-playlist Shelves and seven
  Statistics views share the Games Database interface and original app logo.
- Thirteen themes/variants, optional backgrounds, local DM Sans/Outfit fonts,
  Covers/Cards/compact or extended Row, and independent global/Library search remain.
- Playing now uses an unobtrusive side list **outside** the featured artwork.
- The unified four-tab editor saves dirty fields, keeps Steam/manual sources separate and
  previews Logo/Hero/Cover before Save. Linked App IDs require explicit unlock;
  artwork lookup never clears stored images or synchronizes a player.
- Optional onboarding supports new users, pause/resume/restart and an admin
  checkbox. Six labelled fictional examples require opt-in; reviewed cleanup
  protects concurrent edits, edited examples by default and mixed playlists.
- Daily recommendations offer included/excluded statuses with one 00:00 UTC
  boundary. The dice lets you choose the complete owned library or exactly the
  IDs on the currently displayed page, including its view/filters.
- Positive manual time can replace Steam or add to it; zero/empty uses Steam.
  Grade and Critic remain /100, calculated Score /10. Steam time/sync sit above
  achievement sets, with base/DLC separation and an explicit Steam launch link.
- Two recent-view shortcuts persist actual use without shuffling the visible pair.
  Whole-card/row selection, applied-filter counts, three/four Cards density,
  keyboard/touch favorites and legible native select pickers refine the Library.
- Add Game is a compact title-first modal: an adjacent on/off Steam icon, folded
  secondary fields and mixed batches. Partial retries retain successful receipts;
  optional owned UUIDs prevent repeated manual POSTs from creating another record.
- Direct playlist Edit/Move, compact scroll tools, larger shelf rails and a shorter
  mobile Focus preserve manual lists, four slots and the existing explicit tools.
- Automatic information lookup prefers Steam and fills gaps with Wikidata.
  Empty-only/overwrite choices, source links and checked fields precede Save;
  stale reviews are rejected and personal progress/App ID are left alone.
- Focus-detail management, optional Home/playlist templates, Steam sets, Replays,
  History, catalogs and import/export tools remain available.
- English/Spanish setup, architecture, contribution and user guides accompany
  real application screenshots.

### Compatibility and recovery

Adopt API 3.0.0 first. Review pending collection/onboarding/review-preference and
retry-safe-creation migrations, agree a
consistent WAL-safe backup/isolated restore and retain the prior image digest
before production startup. This is a web/API release, not an Electron package.

Node 22.13+ and the portable root lock are required. Font notices and the existing
application GPL license accompany the static artifact. The explicit product
milestone is recorded by `Release-As: 3.0.0`; publication targets the tested HEAD.

### Boundaries

Public metadata does not supply verified story/completionist durations; no hours
are invented from Steam playtime. Sessions, monthly hours, Replay duration and
historical whole-game 100% timelines are not synthesized. Production hosting,
screen readers, physical devices, Linux-image behavior and actual restore remain
separate verification scopes. Publishing is not deployment or permission to lose
newer user writes.

## Español

Games Database reúne Inicio, Biblioteca, Focus, Playlists, estanterías manuales y
siete vistas de Estadísticas. Conserva logo original, trece temas/variantes, fondos,
fuentes locales, tres layouts y búsquedas global/Biblioteca independientes.

Jugando ahora tiene una lista lateral discreta fuera de la imagen. El editor único
mantiene campos maduros, borradores parciales, fuentes Steam/manual, previews y bloqueo del
App ID. Las consultas de imágenes no borran lo persistido ni sincronizan jugadores.

La guía opcional sirve a usuarios nuevos/existentes y se controla también mediante
check administrativo. Sus seis ejemplos ficticios requieren aceptación; borrar
revisa timestamps y protege editados/listas mixtas. Recomendaciones tiene filtros
de estados y frontera común 00:00 UTC. El dado elige entre toda la biblioteca propia
o los IDs de la página mostrada con sus filtros/vista, sin ampliar el ámbito.

El manual positivo sustituye a Steam o se suma mediante el check; cero/vacío
recupera Steam. Nota/Crítica son /100 y Score calculado /10. Tiempo/sync Steam están
encima de los conjuntos, separando base/DLC y con enlace explícito a Jugar en Steam.
Las dos vistas recientes se persisten sin baile. Selección de tarjeta/fila entera,
contador aplicado, Cards3/4, favoritos teclado/touch y selectores legibles mejoran
Biblioteca. Añadir Juego es un modal compacto con icono Steam on/off junto al título,
ajustes plegados y lotes. Conserva recibos al reintentar y evita repetir altas manuales
con UUID propio. Playlists tiene Editar/Mover directo, mejores rails/scroll y Focus
móvil más corto, conservando las cuatro plazas y listas reales.

El autorrellenado prioriza Steam/Wikidata, permite vacíos/sobrescribir y exige
revisión de fuente/campo. No sustituye datos personales ni App ID. Conflictos
requieren otra revisión. Focus, plantillas, conjuntos Steam, Replays, historial y
herramientas maduras permanecen. Se incluyen docs EN/ES y capturas de la app.

Actualiza primero la API 3.0.0. Antes de producción revisa también las migraciones
de preferencias/tiempo/reintentos y acuerda
copia consistente con WAL/restauración aislada e imagen anterior por digest.
Node 22.13+, lock portátil y avisos de licencias acompañan el artefacto; el hito
se declara con `Release-As: 3.0.0` y se publica el HEAD comprobado.

No se inventan estimaciones desde Steam playtime, sesiones, horas mensuales o
duración de Replays. Hosting, lector de pantalla, dispositivos, imagen Linux y
restauración real mantienen verificación aparte. Publicar no es desplegar ni
permite descartar escrituras posteriores.
