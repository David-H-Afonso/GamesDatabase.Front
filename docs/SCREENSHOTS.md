## What is shown

The `demo-*-en.webp` and `demo-*-es.webp` images are captures of the actual compiled
React application using its real API and a **new isolated demo database**. They are
not design mockups, composited interfaces, a hosted demo or the owner's library.
English and Spanish are the real language setting. WebP encoding is the only image
transformation; the original captures remain outside the repository.

The collection contains 24 real Steam catalog titles. Names, developers, Steam release
dates, available Metacritic scores and separate Logo/Hero/Cover candidates were read
from public Steam endpoints through the application's metadata workflow. Catalog names
and editions are retained as returned, including trademarks or later Store renaming.
Store dates can describe that Steam edition, not the earliest worldwide release.

Statuses ending in **demo**, favorites, playlist membership and Home arrangement are
illustrative organization. No Steam player is linked. There are **no invented or copied
unlock counts, player minutes, personal grades, start/finish dates or Replays**. Missing
player information remains unknown. Focus uses four unlinked catalog records; public
Steam artwork does not require player linking or a background player sync.

The Hades review intentionally starts with some empty catalog fields to demonstrate
current/proposed values. The review shown is a real public-provider response, not an
intercepted success. Optional duration estimates come only from attributed HLTB figures
published by Deku Deals; original source hours and proposed whole-hour rounding appear
in the review. An estimate is not playtime or evidence of completion.

The built-in guide's six fictional examples are a different optional feature, not the
Steam collection shown here. Opening the guide does not create games. The guide image
shows its retained-views chapter without accepting a game sample batch.

## Capture limitations

Screenshots demonstrate the current source, not a new published release or a physical
device certification. They exclude personal accounts, server URLs, credentials and
private test fixtures. Browser viewport emulation is not a real phone or screen reader
test. API README pictures show this same paired client, not a separate API UI.
